# 高手圆桌 Expert Roundtable

**别再每次都打一遍「去找全世界最厉害的人，弄清他们怎么想、怎么做、有什么铁律，再让他们来参与」。**
装一个 skill，整套流程它自己跑——用的是真实、有出处的高手，不是凭空编的人设。

[English](README.md)

```text
> /expert-roundtable 我们的同步引擎要不要改成 CRDT？
```

也可以直接说大白话：「找全世界最厉害的人来一起讨论这个。」

## 它会做什么

1. **点将**：挑 3–5 位在这件事上真正最强的人，其中至少一位唱反调。这个领域以前请过，就直接复用。
2. **档案**：是谁、怎么思考、怎么做事、铁律、会问的问题、盲区——每一条都对得上公开出处。
3. **三轮**：各自出主意 → 互相拆招 → 主持人综合。
4. **一份成果**：先给方案 / 规格 / 决定，再给铁律对照表、留给你拍板的事、什么证据会推翻这个结论。

| 模式 | 用在哪 |
|---|---|
| **圆桌**（默认） | 设计功能、审方案或代码、做决定 |
| **融合** | 把几位高手融合成一位架空代号的新同事，存成 Claude Code 子代理，所有项目都能叫 |
| **历史人物** | 换个意想不到的角度：「秦始皇会怎么看我这个问题？」（明确标注是演绎，不是史实） |

深浅自动调：**快速**（3 人、用现成名单）、**标准**、**深度**（5 人，各自作为独立子代理跑，互不干扰）。

## 和别的「专家团」有什么不同

- **真人、有出处**：不是「大师级」的虚构角色。没有出处的说法，绝不升格成铁律。
- **铁律变成检查项**：每位高手的底线，逐条对照成果，过还是不过。
- **查一次，到处用**：档案存在 `~/.claude/experts/`，第二个项目再要安全审查就不用重查。
- **护栏内置**：不以第一人称冒充在世的人、不编语录、对外标明是演绎、不可逆的事由人拍板。

## 安装

**Claude Code（插件）**

```text
/plugin marketplace add JohnSUNLei/expert-roundtable
/plugin install expert-roundtable@expert-roundtable
```

**任何认 `SKILL.md` 的 AI 工具**（通过 [skills CLI](https://skills.sh)）

```bash
npx skills add JohnSUNLei/expert-roundtable
```

**手动**：把 `skills/expert-roundtable/` 复制到 `~/.claude/skills/`（所有项目）或 `.claude/skills/`（单个项目）。
Claude 网页 / 桌面 App：把这个文件夹压成 zip，在设置里作为自定义 skill 上传。

## 方法从哪来

出自 [量身 AI 课程](https://ailiangshen.com/course) 第 3 课「百家融合法」：找领域公认最强的 3–5 位、按四层各写一张特征卡、
融合成一位架空代号的新人物、试用回炉；再加上我们给企业做方案时用的「有出处的专家组」格式。

## 关于真人

圆桌里每位高手「说」的，都是依据他们**公开**作品的推演，不是本人原话，也不代表本人认可。对外分享时请保留这句说明。
